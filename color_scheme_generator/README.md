# Color Scheme Generator 

This is my first project using an API.I built it to practice working with JavaScript, APIs, form data, DOM manipulation, and responsive CSS.

### About the Project

A simple Color Scheme Generator that uses the [The Color API](https://www.thecolorapi.com/) to generate color palettes based on a selected color and color scheme.

### Features

* Choose a seed color
* Select different color schemes
* Fetch color palettes using an API
* Click HEX values to copy them
* Responsive design for desktop and mobile

### Built With

* HTML
* CSS
* JavaScript
* The Color API

This project is a small step in learning how to work with real-world APIs and integrate external data into a web application.
